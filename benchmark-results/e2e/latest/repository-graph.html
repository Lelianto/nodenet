User guide

Quick start

  1. Choose Architecture, Governance, or Change.
  2. Switch between 2D audit view and 3D exploration.
  3. Search for a node, then select it to reveal its evidence.
  4. Use 1 hop or 2 hops to control how far relationships expand.
  5. Open Display for lines, labels, and camera options.

Terms

Hop
One relationship step between two nodes. 1 hop shows direct neighbors; 2 hops also shows neighbors of those neighbors.
Full graph
Removes the hop limit and includes every visible relationship.
Semantic island
A spatial group based on function: Runtime Code, Structure, Tests & Configuration, Governance Context, or Ownership.
Community
A connectivity-based cluster. Color represents community; position represents semantic function.
Incoming / outgoing
Incoming lines point to the selected node; outgoing lines start from it.
Evidence path
A traceable relationship from code to its Context, owner, or change impact.
All lines
Shows every enabled relationship at low opacity.
Selected lines
Shows only relationships connected to the selected node.
Governance Context
A rule, decision, policy, requirement, or constraint governing code.

Mulai cepat

  1. Pilih Arsitektur, Tata Kelola, atau Perubahan.
  2. Gunakan tampilan 2D untuk audit dan 3D untuk eksplorasi.
  3. Cari lalu pilih node untuk melihat bukti dan relasinya.
  4. Gunakan 1 hop atau 2 hop untuk mengatur seberapa jauh relasi diperluas.
  5. Buka Tampilan untuk mengatur garis, label, dan kamera.

Istilah

Hop
Satu langkah relasi antara dua node. 1 hop menampilkan tetangga langsung; 2 hop juga menampilkan tetangga dari tetangga tersebut.
Grafik penuh
Menghapus batas hop dan menyertakan seluruh relasi yang terlihat.
Pulau semantik
Kelompok berdasarkan fungsi: Kode Runtime, Struktur, Tes & Konfigurasi, Konteks Tata Kelola, atau Kepemilikan.
Komunitas
Cluster berdasarkan keterhubungan. Warna menunjukkan komunitas; posisi menunjukkan fungsi semantik.
Masuk / keluar
Garis masuk mengarah ke node terpilih; garis keluar berawal darinya.
Jalur bukti
Relasi yang dapat ditelusuri dari kode menuju Context, pemilik, atau dampak perubahan.
Semua garis
Menampilkan seluruh relasi aktif dengan opacity rendah.
Garis terpilih
Hanya menampilkan relasi yang terhubung dengan node terpilih.
Konteks Tata Kelola
Aturan, keputusan, kebijakan, kebutuhan, atau batasan yang mengatur kode.
